# Kestrel Customer App

Initial working prototype for **My Kestrels – Garage in your pocket**.

## Features in this prototype
- Customer vehicle dashboard
- MOT and service reminders
- Booking request form
- Customer support area
- Sales link
- Finance link
- Placeholder for AI / WhatsApp integration
- Installable web-app structure

## Run locally
```bash
npm install
npm start
```

The app uses `process.env.PORT`, so it is suitable for deployment on Railway.
